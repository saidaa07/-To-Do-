# PHP To-Do Manager

PHP және MySQL негізінде жасалған тапсырмалар менеджері (To-Do) веб-қосымшасы.

## Жобаның мақсаты

Пайдаланушы тіркеліп, жүйеге кіріп, өз тапсырмаларын ыңғайлы басқара алатын веб-қосымша жасау: тапсырма қосу, өңдеу, жою, санаттарға бөлу, мерзім мен басымдылық қою, іздеу және сүзу.

## Мүмкіндіктер

- Тіркелу, кіру және шығу
- Тапсырма қосу, көру, өңдеу, жою (CRUD)
- Санаттар құру және тапсырмаларды санатқа бекіту
- Басымдылық (төмен / орташа / жоғары) және мерзім (deadline)
- Тапсырманы «орындалды» деп белгілеу
- Атауы бойынша іздеу
- Статус, санат және басымдылық бойынша сүзу
- Деректерді тексеру (валидация) және қауіпсіздік шаралары

## Беттер тізімі

| Бет | Файл | Сипаттамасы |
|-----|------|-------------|
| Тіркелу | `register.php` | Жаңа пайдаланушы тіркеу |
| Кіру | `login.php` | Жүйеге кіру |
| Басты бет | `index.php` | Тапсырмалар тізімі, іздеу және сүзгі |
| Тапсырма формасы | `task_form.php` | Тапсырма қосу және өңдеу |
| Санаттар | `categories.php` | Санаттарды басқару |
| Шығу | `logout.php` | Сессияны жабу |

## Қолданылатын технологиялар

- PHP 8 (PDO)
- MySQL
- HTML5, CSS3, JavaScript
- Git және GitHub

## Дерекқор құрылымы

Дерекқорда 3 кесте бар: `users`, `categories`, `tasks`.

![ER-диаграмма](docs/er-diagram.png)

Толық SQL коды: [`schema.sql`](schema.sql)

## Қауіпсіздік шаралары

- Құпия сөз `password_hash()` арқылы сақталады
- SQL инъекциядан қорғау үшін prepared statements (PDO)
- XSS-тен қорғау үшін `htmlspecialchars()`
- Сессиялармен авторизацияны тексеру
- Форма деректерін серверде валидациялау

## Орнату

1. Репозиторийді клондау: `git clone <репозиторий сілтемесі>`
2. MySQL-де дерекқор құру және `schema.sql` импорттау
3. `includes/db.php` ішінде дерекқор баптауларын көрсету
4. Жобаны XAMPP/OpenServer `htdocs` папкасына орналастыру
5. Браузерде `http://localhost/php-todo-manager` ашу
